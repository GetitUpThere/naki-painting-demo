# Naki Painting — GetitUpThere Ready-to-Offer Kit

## Upload to GitHub Pages
1. Create a new repository, e.g. `naki-painting-demo`.
2. Upload everything from this folder **except the pitch-kit folder if you do not want sales notes public**.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Wait a minute or two for the Pages URL to appear.

`index.html` is at the repository root, so there is no build step.

## Important image note
